# Sub5：其他系统核对修复

> 目标：核对旅行/成就/记忆/打卡/环境感知等系统的完整性并修复缺失

## 核对清单

### 1. 旅行系统（设计6个目的地）
- 确认6个目的地是否全部定义
- 确认短途/中途/长途解锁逻辑
- 确认礼物掉落机制
- 确认明信片生成逻辑
- 确认72小时离线结算

### 2. 成就系统（设计23个成就）
- 互动成就9个：抚摸50/100/500、喂食30/100/300、拍照10/50/100
- 养成成就7个：等级5/10/20、亲密度80/100、连续登录7/30天
- 探索成就7个：服饰10/20/48、家具5/15、明信片10/30
- 确认解锁奖励（庆祝弹窗+音效+钻石）

### 3. 宠物记忆/日记系统
- 确认 InteractionLog 实体记录7种交互
- 确认 PetDiary 每日午夜生成
- 确认6个日记模板匹配优先级
- 确认日记列表页入口（首页信封图标）

### 4. 习惯打卡（3类）
- 喝水/久坐/护眼打卡逻辑
- 连续打卡奖励（3天+5/7天+15/15天+30/30天+50钻石）
- 间隔限制（喝水60min/久坐120min/护眼45min）
- 状态映射（全完成→EXCITED+金色爱心）

### 5. 环境感知
- 天气API（和风天气，每3小时刷新）
- 每日一言API（Hitokoto，每天最多3次）
- 农历节日节气计算
- API失败静默降级

### 6. 经期行为联动
- 4阶段计算逻辑
- 完整周期记录条件（≥2次记录，间隔21-35天）
- 数据物理隔离（仅本地Room）

### 7. 音效系统（14种）
- 确认原7种+新增7种全部实现
- CLICK细分为TAP_LIGHT/TAP_HEAVY

### 8. 拍照功能
- 1080×1080 Bitmap生成
- 渐变背景圆+宠物+装扮+水印
- FileProvider分享

## 修复规则
- 对每个系统逐项核对，列出缺失项
- 补全缺失的逻辑代码
- 不重写已有功能，仅补全缺失部分
