实现方案：图片资源 + 代码轻量动效
  • 主体：AI生成水彩风格插画，100%还原设计图水彩质感与毛茸茸边缘
  • 抠图：PetImageLoader.chromaKeyWhite() 像素级抠除白色背景（亮度>250全透明，225-250平滑过渡抗锯齿）
  • 动效：Compose graphicsLayer 控制 scale 呼吸(0.97↔1.03) + 开心弹跳(1.05+上移)，性能开销极小
  • 换装：后续可叠加 PNG 透明装饰素材，与主体风格统一
  • 扩展：无图物种/颜色自动走矢量 fallback，不影响体验
